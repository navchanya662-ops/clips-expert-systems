# Лабораторна робота 5

Префіксні вирази та родинні відношення.

## Файли

- `expressions.clp`
- `family.clp`
- `test-family.clp`

## Запуск

Відкрийте CLIPS із робочою папкою цієї лабораторної або вкажіть повні шляхи до файлів.

```clips
(clear)
(load "expressions.clp")
(show-expressions)
(load "family.clp")
(load "test-family.clp")
(reset)
(run)
(show-relations)
```
