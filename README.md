# Експертні системи на базі CLIPS

Репозиторій містить результати розробки баз знань та правил у CLIPS
у рамках дисципліни «Інтелектуальні інформаційні технології».

## Структура репозиторію

- [Lab1](Lab1/) — операції з фактами, шаблон person та правила пошуку.
- [Lab2](Lab2/) — шаблони deftemplate та набори deffacts для родини і множин.
- [Lab3](Lab3/) — правила defrule для виведення речень і визначення дефіциту поживних речовин.
- [Lab4](Lab4/) — функції deffunction у системі визначення дефіциту поживних речовин.
- [Lab5](Lab5/) — префіксні арифметичні вирази та логічне виведення родинних відношень.
- README.md — опис проєкту, автор і висновки.

## Використання

Програми виконуються в CLIPS 6.4.2. Завантажте або клонуйте репозиторій,
відкрийте потрібну папку Lab1–Lab5 і виконайте команди з її README.md.
Не завантажуйте всі лабораторні в одне середовище: між незалежними прикладами
виконуйте `(clear)`. `(reset)` створює початкові факти, `(run)` запускає правила,
а `(facts)` показує базу фактів.

## Висновки

Під час виконання робіт я навчився створювати факти й шаблони CLIPS,
формувати базу правил, використовувати функції та виводити нові родинні
відношення. Для збереження результатів код організовано в окремі папки,
до кожної додано опис і команди запуску.

Під час перенесення проєкту потрібно було відокремити код від звітів і
службових файлів та врахувати відмінності робочих папок. До репозиторію
включено файли CLIPS і текстові дані, а в інструкціях використано відносні
шляхи. Git зберігає історію змін, а GitHub дозволяє переглядати проєкт
і передавати викладачу посилання на результати.
