# Лабораторна робота 2

Шаблони та структуровані факти.

## Файли

- `task1.clp`
- `task2.clp`

## Запуск

Відкрийте CLIPS із робочою папкою цієї лабораторної або вкажіть повні шляхи до файлів.

```clips
(clear)
(load "task1.clp")
(load "task2.clp")
(reset)
(facts)
```
Завдання 1 — дев’ять фактів про родину; варіант 1 — множини A, B, C.
